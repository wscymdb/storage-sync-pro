## 🚀 项目背景

在现代前端开发中，面对多套测试环境（`Dev` / `Test` / `Pre` / `Prod`）或者单点登录（`SSO`）联调时，开发者经常需要频繁地在多个浏览器标签页、不同域名或端口之间来回搬运 `Token`、`Authorization` 或特定配置缓存。

传统的 `F12 Application -> Copy -> Switch Tab -> Paste` 步骤极其繁琐低效，且容易出错。

**Storage Sync Pro** 专为解决此痛点而设计。它基于 **React + TypeScript + Vite + Less** 构建，采用极具未来感的 **高透毛玻璃微光拟态（Glassmorphic）视觉风格**，提供了一套**“一键自动抓取 -> 跨页暂存中转 -> 域名网址智能自动回填”**的全自动联调流！

## ⚡ 核心功能介绍

### 1. 🔍 智能过滤与数据高光读取 (Read Panel)
* **一键闪电获取**：点击 `读取当前页`，即时抓取当前标签页下的全部 `LocalStorage` 字段。
* **默认智能过滤**：预设核心筛选 Key（如 `authorization`、`authToken`），从冗长混乱的存储数据中秒速高亮提取关键字段。
* **多功能操作矩阵**：
  * **展开解析 (JSON Format)**：对以 JSON 格式存储的复杂字符串（例如用户信息），提供**美化排版与语法高亮**，免去复制到别处格式化的烦恼。
  * **一键暂存 (Pin to Box)**：点击 `暂存` 按钮将特定字段导入到全局的“数据暂存箱”中，供其他域名写入。

### 2. 📥 跨域数据暂存中转箱 (Write Panel)
* **持久化中转沙箱**：存储在扩展程序沙箱中，不受浏览器关闭或标签页切换影响，数据永不丢失。
* **快捷手动添加**：不仅支持从读取面板导入，还支持手动录入自定义的 Key-Value 键值对。
* **行内编辑与一键写入**：支持双击行内元素直接编辑 Key/Value，并在目标网页点开时，点击底部的 `一键写入当前页` 即可瞬间批量灌入存储。

### 3. 🤖 网址匹配自动写入机制 (Auto-Write Flow)
* **静默瞬时填充**：当在设置中开启 `匹配网址自动写入` 并在下方填入匹配网址（如 `localhost` 或 `dev`）。
* **工作机制**：每次点开插件时，系统只要检测到当前网页 URL 包含您的匹配关键词且暂存箱有数据，便会**在 0.05 秒内自动将暂存箱里的数据全部灌入当前页**，并发出高光绿色的 Toast 成功通知。
* **🛡️ 安全防护 (Safeguard)**：
  * **如果暂存箱为空，自动写入绝对不会被触发**！完美避免了由于写入空值而误清空目标网页原有数据的隐患。
  * 网址匹配采用“模糊子串包含匹配”，比正则更防错，比精准匹配更智能。

### 4. 📇 快捷测试账号簿 (Account Panel)
* **多套凭证随身备忘**：专为测试联调而生，支持保存测试系统网址、对应环境说明、账号、密码及备注（例如：*测试账号1 - 测试服环境*）。
* **小眼睛隐私隐藏**：密码默认以圆点（`••••••••`）脱敏隐藏，点击即可明文显示，防范在公开/演示环境下泄露隐私。
* **一键复制与快速跳转**：账号密码分开一键复制，点击卡片顶部链接可一键新开标签页跳转对应系统。

### 5. ⚙️ 系统首选项配置 (Settings)
* **暗白视觉自适应**：
  * **暗夜霓虹模式 (Dark Mode)**：神秘深邃的黑蓝背景，搭配极光蓝霓虹呼吸微光。
  * **高透玻璃白模式 (Light Mode)**：高透光的极佳白玻璃色调，高对比度防刺眼适配。
* **智能联动设置**：
  * `默认加载时读取`：打开插件即时自动读取当前页存储。
  * `开启筛选数据默认写入`：当前两个开关同时开启时，打开含有筛选 Key 的页面，系统会**默认默默地将其抓取并存入暂存箱**，实现彻底的“零点击无感搬运”！

## 💡 黄金联调工作流（强烈推荐体验）

利用上述功能，您可以配置出极佳的**零点击 SSO 同步流**：

1. **第一步（准备配置）**：
   * 打开系统设置：开启 `默认加载时读取` + `开启筛选数据默认写入`；
   * 打开设置中的 `匹配网址自动写入` 开关，在匹配网址框填入：`localhost`；
   * 默认过滤 Key 中确保包含您需要同步的 Token 字段（如 `authorization`）。
2. **第二步（无感提取）**：
   * 打开您的**线上生产/测试系统**页面，点一下插件（此时生产环境的 Token 被静默读入并自动存进了暂存箱）。
3. **第三步（无感写入）**：
   * 去到您本地的**开发环境 `localhost:3000`** 页面，点一下插件（此时 Token 会被瞬间自动灌入，Toast 弹出自动同步成功！）。
4. **全程零打字、零复制粘贴，仅需打开两次插件，即可完美完成复杂的跨域登录态同步！**

## ⚙️ 开发与构建

### 1. 本地拉取与依赖安装
```bash
# 进入项目目录
cd storage-get-set

# 安装所需依赖 (推荐使用 pnpm)
pnpm install
```

### 2. 本地开发与实时编译
```bash
# 启动 Vite 热更新编译
pnpm dev
```

### 3. 生产环境构建编译
```bash
# 编译 TypeScript 脚本并调用 Vite 构建生产包
pnpm build
```
打包成功后，会在根目录下生成 `dist` 文件夹，这就是最终的 Chrome 扩展包。

### 4. 安装到 Chrome 浏览器
1. 打开 Chrome 浏览器，访问 `chrome://extensions/`（扩展程序页面）；
2. 开启右上角的 **“开发者模式”** 开关；
3. 点击左上角的 **“加载已解压的扩展程序”** 按钮；
4. 选择本项目根目录下的 **`dist`** 文件夹，加载成功即可开始享用！

## 🛡️ 安全与隐私权声明

* 🔒 **100% 物理本地运行**：扩展程序所有抓取的数据（暂存箱、配置项、账号簿）**全部保存在您的浏览器本地沙箱存储（chrome.storage.local/localStorage）中**，绝不会向任何第三方或云端服务器进行上传。
* 🚫 **无外部网络请求**：插件包本身不包含任何网络请求组件，纯内生沙箱运行，数据安全性坚不可摧。
